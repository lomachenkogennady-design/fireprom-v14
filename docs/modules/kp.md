# Модуль: Коммерческое предложение (quote-builder)

## Назначение
Формирование КП с расчётом стоимости лазерной резки, гибки, покраски.

## Тарифы
- Лазерная резка по толщине (9 диапазонов × 3 материала)
- Гибка по толщине (7 диапазонов, ×1.5 за >1000 мм)
- Покраска: 950 ₽/м² × 2 стороны
- Врезки: 2–3 ₽/шт

## Ключевые файлы
- `src/lib/pricing.ts` — тарифы, скидки, НДС
- `src/lib/dxf-import.ts` — парсер DXF для импорта
- `src/components/quote-builder.tsx` — форма КП

## Структура цены
Материал (масса × 1.25 × тариф) + Лазер + Врезки + Гибка + Покраска − Скидка + НДС 22%

## Импорт DXF
Кнопка «📎 DXF → позиция» → `scanDxf()` → авто-заполнение габаритов, длины реза, врезок.
