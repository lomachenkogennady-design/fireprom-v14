# Модуль: Станки (machine)

## Назначение
Характеристики оборудования цеха: гибочные прессы, лазеры, вальцы.
Проверка совместимости детали с конкретным станком.

## Ключевые файлы
- `src/lib/machine.ts` — паспорта станков
- `src/components/machine-check.tsx` — UI проверки
- `src/app/machine/page.tsx` — страница

## Статус
Базовая структура есть, требует наполнения реальными паспортами.
