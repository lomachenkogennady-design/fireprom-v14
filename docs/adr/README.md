# Architecture Decision Records (ADR)

Записи о ключевых архитектурных решениях проекта.

## Формат

Один файл = одно решение.
Имя: NNNN-краткое-название.md
Пример: 0001-use-ollama-for-llm.md

## Структура

# N. Название решения

Дата: YYYY-MM-DD
Статус: предложено | принято | устарело

## Контекст
Почему возник вопрос.

## Решение
Что решили.

## Альтернативы
Что рассматривали и почему отклонили.

## Последствия
Что это даёт и чего лишает.
